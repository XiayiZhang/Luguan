# Luguan 语言参考

## 概述

Luguan 是一种具有晦涩简洁语法的编程语言，支持弱类型推断和内联 Brainfuck。本文件是 Luguan 语言的完整语法和语义参考。

---

## 1. 文件格式

Luguan 源文件使用扩展名 `.🦌🧪️`（鹿角+试管 emoji 组合）。

## 4. 类型系统

Luguan 使用弱类型系统，类型在函数签名中显式声明，但变量无需类型注解。

### 基本类型

| 类型关键字 | 说明 |
| :-: -----| :-: |
| `int` | 整数类型 |
| `bool` | 布尔类型 |
| `optional <type>` | 可选类型 |

### 可选类型

使用 `optional` 关键字声明可选类型，`null` 表示无值，`some(expr)` 包装值。

```text
y = null;
z = some(1);
```

---

## 5. 变量与赋值

变量无需预先声明，直接赋值即可创建。

```text
x = 42;
name = "Luguan";
flag = true;
```

### 索引赋值

支持对列表中的元素进行赋值：

```text
arr = [1, 2, 3];
arr[0] = 99;   // arr 变为 [99, 2, 3]
```

## 7. 语句

### 表达式语句

以分号结尾的表达式。

```text
print x;
x = x + 1;
```

### 打印语句

```text
print <表达式>;
```

输出表达式的值。列表会以 Haskell 的 `show` 格式输出。

### 输入语句

```text
input <变量名>;
```

从标准输入读取一个整数并赋值给变量。输入非整数将导致错误。

### 赋值语句

```text
<变量名> = <表达式>;
```

### 索引赋值

```text
<列表表达式>[<索引表达式>] = <表达式>;
```

### if 语句

```text
if (<条件>) {
    // then 分支
} else {
    // else 分支（可选）
}
```

### while 语句

```text
while (<条件>) {
    // 循环体
}
```

### 块语句

使用花括号 `{ }` 包裹多条语句，形成一个块。

## 8. 函数

### 函数定义

```text
func <函数名>(<参数1>: <类型1>, <参数2>: <类型2>, ...): <返回类型> {
    // 函数体
}
```

### 示例

```text

```

## 9. 内置函数

Luguan 提供以下内置函数：

### `bf(mem, program)`

执行 Brainfuck 代码。

- **参数**：
  - `mem`：列表 `[Int]`，初始内存
  - `program`：字符串，Brainfuck 代码
- **返回**：列表 `[Int]`，Brainfuck 执行的输出

```text
r = bf([0, 1, 2], "++.>++.>++.");
print(r);  // 输出 [2, 3, 4]
```

### `read(list, index)`

读取列表中指定索引的元素。

- **参数**：
  - `list`：列表
  - `index`：整数索引
- **返回**：索引处的元素

```text
val = read([10, 20, 30], 1);  // val = 20
```

### `insert(list, index, element)`

在列表指定位置插入元素。

- **参数**：
  - `list`：列表
  - `index`：插入位置（0 到 length 之间）
  - `element`：要插入的元素
- **返回**：新列表

```text
arr = insert([1, 2, 3], 1, 99);  // arr = [1, 99, 2, 3]
```

### `replace(list, index, element)`

替换列表指定位置的元素。

- **参数**：
  - `list`：列表
  - `index`：替换位置
  - `element`：新元素
- **返回**：新列表

```text
arr = replace([1, 2, 3], 0, 99);  // arr = [99, 2, 3]
```

### `delete(list, index)`

删除列表指定位置的元素。

- **参数**：
  - `list`：列表
  - `index`：删除位置
- **返回**：新列表

```text
arr = delete([1, 2, 3], 1);  // arr = [1, 3]
```

## 11. 完整示例

### Hello World

```text
print "hello world";
```

### if-else

```text
if (true) {
    print 42;
} else {
    print 0;
}
```

### while 循环

```text
x = 5;
while (x >= 0) {
    print x;
    x = x + 1;
}
```

### 冒泡排序

```text
a = [2, 5, 1, 3, 9, 6, 8, 7, 4];
len = 9;
d = 0;
while (d < len - 1) {
    b = 0;
    while (b < len - 1 - d) {
        if (read(a, b) > read(a, b + 1)) {
            temp = read(a, b);
            a = replace(a, b, read(a, b + 1));
            a = replace(a, b + 1, temp);
        }
        b = b + 1;
    }
    d = d + 1;
}
print(a);
```

### Brainfuck 内联

```text
r = bf([0, 1, 2], "++.>++.>++.");
print(r);
```
